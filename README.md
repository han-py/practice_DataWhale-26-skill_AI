## 笔记（汇总）
根据 `报错内容.md` 与 `Skill审核驳回问题分析&直播课建议参考.md`，最容易被驳回的是：动态内容未经统一清洗直接写入 Markdown/CSV，以及外部平台残留未清理。

### 1) 动态字段统一清洗（先清洗，后写入）
适用对象：用户输入、检索结果、文件解析结果、标题、摘要、关键词、表格单元格、引用原文、链接展示文本。

推荐顺序（固定流程）：
1. 去首尾空白；内部连续换行压平成单空格
2. 转义 Markdown 表格敏感字符：`|`（避免破坏列结构）
3. 处理 HTML 特殊字符：`<` `>` `&`
4. 去活化 Markdown 链接/图片语法：`[]()`、`![]()`（按纯文本输出）
5. 危险协议拦截：`javascript:`、`data:`（大小写不敏感）
6. 公式前缀防护：按“首个非空白字符”判断是否为 `=` `+` `-` `@`，命中则前置单引号

### 2) 公式前缀判定的关键细节
不要只看第一个字符，要先跳过前导空白（空格、制表符、全角空格）再判断。

- 需要拦截：` =SUM(1,1)`、`\t+CMD`、`　-HYPERLINK(...)`、`@calc`
- 处理方式：在有效起始字符前增加单引号，例如 `'=SUM(1,1)`

### 3) Markdown/CSV 分场景要求
- Markdown 表格：必须完成“换行压平 + `|` 转义 + HTML 字符处理 + 协议去活化 + 公式前缀防护”
- Markdown 正文/标题/列表/引用：至少完成“HTML 字符处理 + 链接/图片去活化 + 协议拦截”
- CSV 导出：所有字段都做“首个非空白字符公式前缀检测”，命中即前置单引号

### 4) 外部平台残留清理（提交前必做）
全仓搜索并复查是否存在非必要外部平台引用：
`openai`、`claude`、`gemini`、`anthropic`、`google`、`youtube`、`CLAUDE.md`。

注意：代码、注释、文档、文件名、配置文件都要查。

### 5) 提交前最小自检清单（建议逐项打勾）
- [ ] 所有动态字段都经过同一套清洗函数，不存在“某些字段漏处理”
- [ ] Markdown 表格字段已处理 `|`、换行、`< > &`、反引号、链接/图片语法、危险协议
- [ ] CSV 字段已按首个非空白字符做 `= + - @` 检测并前置单引号
- [ ] 来源标题/摘要/链接展示文本/URL 已清洗或校验后再输出
- [ ] 全仓外部平台关键词已搜索并清理非必要残留
- [ ] 示例命令和测试可运行，Windows 控制台输出无编码报错

一句话记忆：先统一清洗，再格式化输出；先做首个非空白字符判断，再谈公式前缀防护。
